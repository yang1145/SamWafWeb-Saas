# SamWafWeb-Saas 前端商业化改造计划

## 背景与目标

本项目是 Vue 3 + TypeScript + Vite + TDesign 的 WAF 管理前端（SaaS 多租户功能已完成）。当前页面保留了大量开源社区痕迹：SamWaf 标识/Logo/favicon、顶栏微信公众号二维码与 `mailto:samwafgo@gmail.com`、doc.samwaf.com / GitHub / Gitee / service.samwaf.com 外链、仪表盘上的"版本升级"弹窗、登录页极简无品牌感。本次改造目标：

1. **去除 SamWaf 品牌标识**，品牌文案收敛到单一配置文件，后续一行可改名
2. **去除顶栏 SamWaf 相关联系方式**（微信二维码、邮件、外链文档）
3. **全面商业化**：登录页重设计 + 仪表盘去开源痕迹 + 侧栏/页脚/关于弹窗焕新

已确认决策：**中性占位名**（"WAF 安全管理平台" / "WAF Security Console"，不含品牌词）· **纯文字标识 Logo** · **全面商业化** · **保持现有默认蓝色**（8 色主题切换保留）。

## 第一步：品牌收敛 —— 新建 `src/config/brand.ts`（单一来源）

```ts
export const BRAND = {
  nameZh: 'WAF 安全管理平台',        // 中文产品名（占位，可随时一行改掉）
  nameEn: 'WAF Security Console',    // 英文产品名
  nameShort: 'WAF 控制台',           // 侧栏文字标识（折叠态显示 "WAF"）
  copyrightHolder: 'WAF',            // 版权归属主体
  copyrightStartYear: 2022,
  supportEmail: '',                  // 留空 = 全站隐藏邮件联系入口
  docUrl: '',                        // 留空 = 全站隐藏在线文档入口
  serviceUrl: '',                    // 留空 = 隐藏在线客服
};
export function getBrandName(): string  // 按 localStorage.lang 返回中/英产品名
```

在 `src/main.ts` 用 `i18n.global.mergeLocaleMessage()` 注册 `brand.*` 词条，所有组件统一 `t('brand.product')` 引用，实现"一处改名、全站生效"。

## 第三步：顶栏清理（`src/layouts/components/LayoutHeader.vue`）

- **移除**：微信公众号按钮 + 二维码对话框（微信图标、`assets-mp-samwaf.png`）；"联系我们"邮件按钮（`sendMail`/`MailIcon`）
- **联动清理**：`SystemMonitorWidget.vue` 中的"SamWaf开源防火墙"链接与 `open-wechat` emit；删除素材 `src/assets/assets-mp-samwaf.png`
- **帮助文档按钮**：`brand.docUrl` 配置了才显示（默认占位配置为空 → 隐藏）
- 保留：搜索、系统监控、通知铃铛、页面配置、语言切换、用户菜单 —— 顶栏更干净、更商业

## 第四步：登录页重设计（`src/pages/login/index.vue`）

纯 CSS 实现（无图片资源）、完全跟随 TDesign 明暗主题变量，登录/2FA/强制改密逻辑**一行不动**：

- **左右分栏**（≥900px）：左侧品牌区 —— 品牌色渐变底（`var(--td-brand-color-*)`）+ 装饰性网格/光斑，产品名大标题 + 副标语 + 3 条产品价值点（网站防护 / 攻击拦截 / 流量分析，配 TDesign 图标）；右侧登录卡片（原表单迁移，顶部加产品名小标识）
- **移动端/窄屏**：隐藏左侧品牌区，居中卡片 + 淡渐变背景
- **页脚**：中性版权；移除 doc.samwaf.com 两个链接
- 新增 i18n 词条：`login.welcome_*`、`login.feature_*`

## 第五步：全站商业化视觉

1. **仪表盘**（`src/pages/dashboard/base/index.vue`）：移除开源版本"升级提示"横幅 + "一键升级"弹窗（`upgradeTipMessage`/`upgradePopup` 相关块，apis 不动）；保留降级警告（运维有用）和新手引导 swiper（改用中性文案，是 SaaS 正常的 onboarding）
2. **侧栏版本入口**（SideNav）：样式收敛为次要色弱化显示，红色 `debug` 标签改为小号 warning tag（不再大红刺眼）
3. **杂项中性化**（均为前端安全改动）：webhook 预设 `group: "SamWaf"`/`X-Title: SamWaf Alert` → 中性（`webhook_presets.ts`）；规则前缀默认 `SamWafRule` → `WafRule`（`rule-builder/index.vue`）；导出文件名 `samwaf_stats_*.csv`、`samwaf_diag_*.zip`、`samwaf-local-ca.crt` → 中性前缀
4. **favicon**：新建 `public/favicon.svg`（蓝色圆角方块 + 白色 "W" 文字，纯文字标识风格）；若环境可行用脚本同步产出 `.ico` 兜底，否则仅 SVG（现代浏览器均支持）
5. 其余 40 个业务表格页**保持现有 TDesign 风格不动**（已天然统一），避免大规模回归风险

## 明确不改动（后端耦合/技术标识，改名会直接故障）

localStorage 键 `samwaf_*`/`__samwaf_*`、后端注入的 `#samwaf-ui-config` 脚本 id、请求头/路径 `X-SamWaf-Access-User`/`/samwaf_access`/`samwaf_ac`、阻断页模板变量 `[[.SAMWAF_*]]`、`__SAMWAF_CLEAR__` 哨兵、i18n 中 "SamWaf Local CA"（后端证书主题名）、`samwaf migratedb` CLI 提示、`samwaf_core`/`samwaf_stats` 库名、构建插件名与 CI 文件。README/docs 属于文档层，不在本次页面改造范围。

## 验证方案

- `npm run build`（vue-tsc 类型检查 + vite 构建）通过
- 残留审计：`grep -ri samwaf src/` 结果应仅剩上述"明确不改动"白名单条目
- `npm run dev` 起本地服务，用浏览器实测：登录页（亮/暗主题、窄屏）、侧栏文字标识、顶栏无微信/邮件按钮、仪表盘无升级弹窗、语言切 English 后无 SamWaf 残留（内页需后端 127.0.0.1:26666 在运行；若后端未起则验证到登录页 + 构建产物为止并说明）

## 风险与边界

- 品牌占位名后续正式改名 = 只改 `brand.ts` 两行 + i18n 词条已全部走配置，成本极低
- 所有删除的素材文件（mp 二维码、旧 logo SVG）在 git 历史可随时找回
- 不提交 git（除非你要求）；改造后你可用 `npm run dev` 先行验收
